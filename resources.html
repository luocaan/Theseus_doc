资源文件用途对应文档
mod-api-0.6.7.jar模组 API 编译依赖（瘦身 jar，仅含 com.seecmd.mod.api.* 与 com.seecmd.mod.api.spi.*）。模组编译期唯一需要引用的宿主产物，运行期由游戏宿主提供开发指南 · 环境搭建 / API 参考

文档页面

页面内容适用读者
快速上手从零开始：创建项目 → 编写最小模组 → 打包 → 加载到游戏想尽快跑通第一个模组的开发者
开发指南完整开发流程：环境搭建 → 最小模组 → 核心示例（替换 HUD / 自定义场景 / 新音符类型 / 判定修改 / 事件监听）→ 打包发布需要系统性学习的第三方开发者
API 参考com.seecmd.mod.api 全部接口的签名定义与行为契约（唯一权威签名）写代码时查阅签名的开发者
架构设计模组系统的分层结构与核心抽象（面向开发者的公开版）想理解模组系统工作原理的开发者
资源制作指南音符皮肤（图片 / 字符）等自定义资源的制作方法，多数无需编程不想写代码、只做资源内容的玩家
THS 简易语言用简单脚本做出游戏模组，无需 Java 基础零基础入门用户

推荐路径

  • 会写 Java：下载 mods-template 模板 → 解压 → 写代码 → 双击 build.bat → 把 jar 放入游戏 mods/ 目录。见 快速上手。
  • 不会写 Java：直接看 THS 简易语言，用脚本就能做出滤镜 / HUD / 特效。
  • 只想做资源：看 资源制作指南，放好文件即可被游戏识别。
