快速上手

从零开始：创建项目 → 编写最小模组 → 打包 → 加载到游戏

什么是 SEECMD 模组

SEECMD 模组系统允许你用 Java 为游戏编写扩展。模组可以：

  • 注册新内容：自定义音符类型、游戏模式、判定等级、谱面扩展段
  • 覆盖渲染：隐藏原版 HUD 组件并在画面上自绘
  • 修改判定：调整判定窗口、改写判定结果、注册新的判定等级
  • 监听事件：订阅游玩事件（判定、连击、开始/结束）与全局事件
  • 控制游戏状态：暂停/恢复/变速/跳转、压入自定义场景、播放音效
  • 与玩家交互：向玩家展示提示 / 弹窗信息、解锁收集品、注册自定义音频

所有 API 位于 com.seecmd.mod.api 包中，标注 @Experimental（实现中，可能调整）。

最快路径：官方模板（推荐）

不需要从零搭工程、不需要装 Maven、不需要配置依赖——下载模板，解压即用。

  1. 下载 mods-template-0.1.0.zip（已内含 mod-api jar 与 build.bat）并解压。
  2. 编辑 build.bat 顶部的 4 个变量：MOD_ID、MOD_NAME、MOD_VERSION、MOD_CLASS（指向你的入口类）。
  3. 在 src\main\java 下写你的模组代码（参考模板里的 ExampleMod），资源放 src\main\resources。
  4. 双击 build.bat，产物在 target\<MOD_ID>-<MOD_VERSION>.jar。
  5. 把 jar 复制到游戏的 mods\ 目录，启动游戏，模组即被加载。

你唯一需要的环境是 JDK 17+（安装时勾选「加入 PATH」即可）。其余全部由模板代劳。

最小模组只需实现 Mod 接口：

java
package com.example.helloworld;

import com.seecmd.mod.api.Mod;
import com.seecmd.mod.api.ModContext;
import com.seecmd.mod.api.ModInfo;

import java.util.List;

public class HelloWorldMod implements Mod {

    @Override
    public ModInfo info() {
        return ModInfo.of(
                "com_example_helloworld",   // id：小写下划线
                "Hello World",              // 显示名
                "0.1.0",                    // 版本
                List.of("Alice"),           // 作者
                "最小模组示例"               // 描述
        );
    }

    @Override
    public void onLoad(ModContext ctx) {
        // 模组被启用时调用一次
        ctx.getLogger().info("Hello World 模组已加载");
        // 向玩家展示提示：toast 数秒后自动消失；重要信息可用 ctx.notifier().dialog("...", 5000)
        ctx.notifier().info("Hello World 模组已加载");
    }
}

Mod.info() 是唯一必须实现的方法。需要参与游玩（覆盖渲染 / 修改判定 / 监听事件）时，改实现 GameplayMod 接口（继承自 Mod）。ModContext 是模组的「工具箱」：日志、数据目录、配置、四大注册表、能力注入、用户通知等，见 API 参考。

验证模组已加载

模组加载成功时，控制台会打印模组日志（[com_example_helloworld] Hello World 模组已加载），游戏内也会弹出你通过 notifier() 发送的提示。若什么都没发生：

  • 确认 jar 放在 mods\ 目录（与游戏 data\ 同级）。
  • 确认 jar 的 META-INF/MANIFEST.MF 含 Seecmd-Mod-Class（模板已自动生成，改类名时记得同步 build.bat 的 MOD_CLASS）。
  • 查看游戏日志是否有模组加载报错。

进阶：手工搭建工程

如果你已有自己的构建体系（Maven / Gradle / IDE），也可以手工引入依赖。

重要：依赖 scope 必须为 provided（Maven）或 compileOnly（Gradle）。API 由宿主在运行期提供，模组 jar 不得把宿主类打进去。

第一步：安装 mod-api 到本地仓库（只需一次）

从 这里 下载 jar，执行：

text
mvn install:install-file -Dfile=mod-api-0.6.7.jar -DgroupId=com.seecmd -DartifactId=mod-api -Dversion=0.6.7 -Dpackaging=jar

第二步：声明依赖

Maven 示例：

xml
<dependencies>
    <dependency>
        <groupId>com.seecmd</groupId>
        <artifactId>mod-api</artifactId>
        <version>0.6.7</version>
        <scope>provided</scope>
    </dependency>
    <dependency>
        <groupId>com.google.code.gson</groupId>
        <artifactId>gson</artifactId>
        <version>2.10.1</version>
        <scope>provided</scope>
    </dependency>
</dependencies>

Gradle 示例：

groovy
dependencies {
    compileOnly 'com.seecmd:mod-api:0.6.7'
    compileOnly 'com.google.code.gson:gson:2.10.1'
}

打包：编译后打包为标准 jar，manifest 必须包含以下条目：

manifest
Manifest-Version: 1.0
Seecmd-Mod-Id: com_example_helloworld
Seecmd-Mod-Class: com.example.helloworld.HelloWorldMod
Seecmd-Mod-Name: Hello World
Seecmd-Mod-Version: 0.1.0
Seecmd-Mod-Authors: Alice
Seecmd-Mod-Description: 一个示例模组，演示 SEECMD 模组 API 基础用法

完整配置参考模板中的 pom.xml（已配置好 maven-jar-plugin 的 manifest 生成）。

加载到游戏

  1. 把打包好的 xxx.jar 放进游戏工作目录下的 mods/ 文件夹（与 data/ 同级）。
  2. 启动游戏，加载器自动扫描 mods/ 目录，读取 manifest 定位入口类并注册。
  3. 模组数据目录在 data/mods/<modId>/（首次访问自动创建）。
  4. 启用状态持久化在 data/settings.json 的 enabledMods，也可用外置工具 mods/mod-manager.jar 管理。

模组 id 命名规范

  • 小写下划线，如 com_example_helloworld。
  • 不得以 builtin_ 开头（保留给内置模组）。
  • 建议使用反向域名前缀避免冲突。
