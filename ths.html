THS 简易语言开发文档

面向零基础，用简单脚本就能做出游戏模组

什么是 THS？

THS 是一种简单的脚本语言，专门为 SEECMD 游戏设计。你不需要学习 Java 就能用 THS 做出自己的模组。

THS 能做什么：

  • 给画面加滤镜效果（花屏、黑白、暗角）
  • 自定义连击显示
  • 调整判定宽容度
  • 在音符判定时放特效
  • 检测特定的游戏事件并触发效果

快速开始

1. 创建文件

在游戏目录的 mods 文件夹中，创建一个以 .ths 结尾的文件。

2. 写模板

text
# 这是我的第一个 THS 模组
name "我的第一个模组"
id "my_first_mod"
author "你的名字"
version "1.0"

3. 添加效果

text
# 启用花屏滤镜
set_filter "glitch" {
    intensity = 0.5
    speed = 1.0
}

4. 在游戏里启用

  1. 启动游戏，进入主菜单的"模组管理"
  2. 找到你的模组，启用它
  3. 进入游玩，效果就出现了

在线体验

不用启动游戏，直接在下面试玩 THS。选择一个预设示例，修改脚本里的参数，点击"运行"，右侧的模拟游玩画面会实时展示脚本效果。想改哪里就改哪里，改坏了点"重置"再来。

完整示例

text
# 综合示例
name "我的综合模组"
id "my_ultimate_mod"
author "你的名字"
version "1.0"

# 启用花屏和暗角滤镜
set_filter "glitch" {
    intensity = 0.3
    speed = 0.8
}

set_filter "vignette" {
    radius = 0.3
    darkness = 0.5
}

# 自定义连击显示
hud "combo" {
    position = "top"
    color = "0 255 200"
    font_size = 48
}

# 放宽判定
set_judgment "wide" {
    perfect = 80
    great = 150
}

# 连击到 100 触发闪白庆祝
on_combo 100 {
    trigger "flash" {
        color = "255 255 255"
        duration = 0.5
    }
}

# 每帧绘制分数
on_render {
    color 255 255 255
    text "Score: " + score 20 20
}

连续 Miss 提醒示例

连续 Miss 3 次时，在屏幕上叠加一层白色提示层，同时显示警示文字，1.5 秒后自动消失。中途只要命中一次，连续计数就会清零重新开始。

text
# 连续 Miss 提醒
name "连续 Miss 提醒"
id "miss_streak_demo"
author "你的名字"
version "1.0"

on_miss_count 3 {
    trigger "message" {
        text = "注意节奏！"
        color = 255 255 255
        opacity = 0.85
        duration = 1.5
    }
}
  • on_miss_count 3 只统计连续 Miss，连续 3 次未命中才触发
  • message 模板的 color 是提示层颜色（这里为白色）、opacity 是层的不透明度、duration 是显示时长
  • 不想要提示层、只显示文字时，去掉 color 和 opacity 两个参数即可
  • 在「在线体验」中选择预设「连续 Miss 提醒」即可直接试玩这个效果
